# Інформація про магазин для AI-помічника

Цей файл AI-помічник читає під час кожної розмови. Пишіть сюди звичайним текстом
усе, що він має знати про магазин: контакти, доставку, оплату, послуги, акції.
Після змін перезапустіть сайт (npm run dev).

## Контакти
- Назва: АгроМаркет
- Телефон: +380 (67) 000-00-00
- Email: info@agromarket.ua
- Адреса складу: Україна, м. Київ, вул. Польова, 1
- Графік роботи: Пн–Пт 8:00–18:00, Сб 9:00–14:00

## Доставка
- Нова Пошта — по всій Україні, 1–3 дні.
- Власний транспорт — для великих партій безпосередньо у господарство.
- Самовивіз зі складу в робочий час.
- Вартість доставки розраховує менеджер після оформлення замовлення.

## Оплата
- Безготівковий розрахунок з ПДВ (рахунок-фактура) для підприємств і ФГ.
- Оплата на картку.
- Оплата при отриманні.

## Оптові ціни
- Для багатьох товарів діють оптові ціни: що більша партія, то нижча ціна за одиницю.
  Конкретні пороги видно в даних товару (поле price_tiers).

## Послуги
- Професійне очищення та протруювання насіння мобільними комплексами
  безпосередньо в господарстві клієнта (сторінка /services).
- Безкоштовна консультація агронома: підбір насіння, системи захисту та живлення.
