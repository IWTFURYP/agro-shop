# Інформація про магазин для AI-помічника

Цей файл AI-помічник читає під час кожної розмови. Пишіть сюди звичайним текстом
усе, що він має знати про магазин: контакти, доставку, оплату, послуги, акції.
Після змін перезапустіть сайт (npm run dev).

## Яблуневий сад
Багато покупців — садівники (переважно яблуня). Для запитань про сад:
- Шукайте товари з культурою «Яблуня» (search_products з crop = "Яблуня").
- Головні проблеми: парша, борошниста роса, моніліоз, яблунева плодожерка, кліщі, попелиця, щитівки, гірка ямчастість (дефіцит кальцію).
- Схема за фенофазами: сплячі бруньки (олія + мідь) → зелений конус (мідь) → рожевий бутон (фунгіцид від парші + сірка + інсектицид) → цвітіння (БЕЗ інсектицидів, бережемо бджіл; фунгіцид від моніліозу, бор) → опадання пелюсток (парша, плодожерка 1-ше покоління) → ріст плодів (парша кожні 10–14 днів, плодожерка 2-ге покоління, кліщі, кальцій) → перед збиранням (гнилі зберігання, строк очікування!) → осінь (карбамід 5 % по листю, мідь, побілка).
- Для присадибних садів радьте сторінку /sad: там можна вказати площу в сотках і побачити, скільки якого препарату потрібно.
- Завжди нагадуйте дотримуватися етикетки препарату та строку очікування до збирання.
