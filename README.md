# 🌱 АгроМаркет — інтернет-магазин агротоварів

Засоби захисту рослин, насіння, мінеральні та мікродобрива, сільгосптехніка.

- **Фронтенд:** Vue 3 + Vite + Vue Router + Pinia, іконки Lucide (папка `frontend`)
- **Бекенд:** Node.js + Express + SQLite (папка `backend`)
- **База даних:** файл `backend/data/shop.db` — створюється автоматично при першому запуску
- **Фото:** у базі зберігаються **тільки посилання** на фото, а не самі файли

---

## 1. Що потрібно встановити (один раз)

1. **Node.js 22.13 або новіший** (рекомендовано версію 24 LTS) — https://nodejs.org
   Перевірити: відкрийте термінал і введіть `node -v`
2. **VS Code** — https://code.visualstudio.com
   При відкритті проєкту VS Code запропонує встановити розширення **Vue (Official)**: погодьтесь.

## 2. Запуск з VS Code

1. `File → Open Folder…` → оберіть папку `agro-shop`
2. Відкрийте термінал: `Terminal → New Terminal` (або <kbd>Ctrl</kbd>+<kbd>`</kbd>)
3. **Перший раз** встановіть залежності:
   ```bash
   npm install
   ```
4. Запустіть сайт:
   ```bash
   npm run dev
   ```
5. Браузер відкриється сам. Якщо ні, відкрийте **http://localhost:5173**

> Швидкий запуск: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> (завдання «2. Запустити сайт»)
> або вкладка **Run and Debug** (<kbd>F5</kbd>) → «Запустити сайт (бекенд + фронтенд)».

Зупинити сайт: у терміналі натисніть <kbd>Ctrl</kbd>+<kbd>C</kbd>.

### Як відкрити сайт з телефону

1. Телефон і комп'ютер мають бути в **одній Wi-Fi мережі**.
2. Замість `npm run dev` запустіть:
   ```bash
   npm run dev:phone
   ```
3. У терміналі з'явиться рядок `➜  Network: http://192.168.X.X:5173/` — відкрийте цю адресу в браузері телефона.
4. Якщо Windows спитає про доступ до мережі для Node.js — дозвольте для **приватних мереж**.

Не виходить? Перевірте, що Wi-Fi у Windows має тип «Приватна мережа», і що телефон не в гостьовій мережі роутера.
Кнопка «Де я зараз» у щоденнику саду на телефоні через цю адресу не працює (браузер дозволяє геолокацію лише на https) — знайдіть село за назвою.

### Як надіслати посилання людині з іншого міста

Людина просто відкриває посилання — їй нічого не треба встановлювати.

1. Один раз встановіть Cloudflare Tunnel: `winget install --id Cloudflare.cloudflared` і перезапустіть VS Code.
2. Запустіть:
   ```bash
   npm run share
   ```
3. У терміналі з'явиться посилання `https://….trycloudflare.com` — надішліть його у Viber/Telegram.

Сайт доступний, поки на вашому комп'ютері працює ця команда. Після перезапуску посилання буде нове.
Не забудьте змінити пароль адмінки.

## 3. Адмін-панель

- Адреса: **http://localhost:5173/admin**
- Логін: `admin`
- Пароль: `admin12345`

⚠️ Змініть пароль одразу на сторінці «Огляд» в адмінці (блок «Змінити пароль»).

В адмінці можна:
- додавати, редагувати й видаляти **товари** (ціна, стара ціна для знижки, залишок, фото, характеристики);
- керувати **категоріями** та **виробниками**;
- переглядати **замовлення** й змінювати їх статус;
- переглядати **заявки** (консультація агронома, протруювання насіння, зворотний дзвінок).

Якщо поле «Ціна» порожнє, на сайті показується **«Ціна за запитом»** (зручно для техніки).

| **SEO** | кожна сторінка має свій заголовок і опис; товари й статті мають розмітку schema.org | Карта сайту: `/sitemap.xml`, `/robots.txt`. Після публікації вкажіть адресу сайту в `backend/.env` → `SITE_URL` і додайте sitemap у [Google Search Console](https://search.google.com/search-console) |

### Підказки населених пунктів

У формі замовлення поле «Населений пункт» підказує міста й села України вже з перших літер
(«топо» → «с. Топорівці — Чернівецька обл., Чернівецький р-н, Топорівська громада») і саме заповнює область.
Довідник — офіційний КАТОТТГ (≈ 29 700 населених пунктів) у файлі `backend/src/data/settlements.json`,
пошук — `GET /api/settlements?q=топо`. Можна уточнювати областю чи районом: «топорівці черн».
Компонент для інших форм — `frontend/src/components/SettlementInput.vue`.

Якщо ви вже запускали попередню версію — база оновиться автоматично (нові таблиці й поля додаються самі, дані не зникають).

## AI-помічник для покупців

У правому нижньому куті сайту є кнопка **«AI-помічник»** (на телефоні — кругла кнопка над нижньою панеллю).
Помічник працює на моделі Claude від Anthropic і вміє:

- шукати товари в каталозі за назвою, культурою чи проблемою («септоріоз пшениці», «бур'яни в соняшнику»);
- показувати картки товарів з кнопкою «в кошик»;
- рахувати, скільки препарату потрібно на N гектарів, з урахуванням оптових цін;
- відповідати про доставку, оплату й послуги;
- за згодою клієнта створювати заявку на дзвінок (вона з'являється в адмінці → «Заявки» з типом «Заявка від AI-помічника»).

### Як увімкнути

1. Зареєструйтеся на https://platform.claude.com, поповніть баланс і створіть ключ API (розділ **API Keys**).
2. Скопіюйте `backend/.env.example` у `backend/.env` (якщо ще не зробили) і впишіть ключ:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
3. Перезапустіть сайт (`Ctrl+C`, потім `npm run dev`). Кнопка помічника з'явиться автоматично.

Без ключа сайт працює як звичайно, кнопка помічника просто прихована.

### Налаштування

| Що | Де |
|---|---|
| Що помічник знає про магазин (контакти, доставка, оплата, акції) | `backend/src/assistant/knowledge.md` — звичайний текст, редагуйте й перезапустіть сайт |
| Модель | `backend/.env` → `ASSISTANT_MODEL` (за замовчуванням `claude-opus-5-5`; дешевший варіант — `claude-haiku-5-5`) |
| Ретельність відповідей | `backend/.env` → `ASSISTANT_EFFORT`: `low` (за замовчуванням, швидко й дешево), `medium`, `high` |
| Поведінка, тон, правила | `backend/src/assistant/index.js` → `SYSTEM_PROMPT` |

**Вартість.** Оплата за використання API, за кількістю токенів (ціни: https://platform.claude.com/pricing).
Щоб захистити бюджет, з однієї IP-адреси можна надіслати не більше 30 повідомлень за 15 хвилин, а одна розмова
обмежена 40 повідомленнями. Витрати видно в кабінеті platform.claude.com → Usage; там же можна задати місячний ліміт.

## 5. Як додати фото товарів

У базі зберігається лише посилання. Є два способи:

**А) Фото з інтернету.** Скопіюйте адресу картинки (`https://…/photo.jpg`) і вставте в поле
«Посилання на головне фото» в адмінці.

**Б) Власні файли.** Покладіть фото в папку `frontend/public/images/`
(наприклад, `glifosat.jpg`) і вкажіть в адмінці посилання `/images/glifosat.jpg`.

Для галереї товару натисніть «+ Додати фото» та вставте додаткові посилання.

## 7. Демо-дані

При першому запуску в базу додаються демонстраційні категорії, виробники та ~30 товарів
(назви, ціни та описи **умовні**). Змініть їх в адмінці під реальний асортимент.

Повністю очистити каталог і замовлення та повернути демо-дані:
```bash
npm run seed:reset
```

## 8. Публікація (production)

```bash
npm run build   # збирає фронтенд у frontend/dist
npm start       # один сервер на http://localhost:3000 — і сайт, і API
```
Перед публікацією створіть `backend/.env` із власними `ADMIN_PASSWORD` і `JWT_SECRET`.

```
│       └── routes/         ← catalog, orders, requests, auth, admin
└── frontend/
    ├── public/images/      ← сюди можна класти власні фото
    └── src/
        ├── config.js       ← назва, контакти, довідники
        ├── router.js       ← сторінки сайту
        ├── api.js          ← запити до бекенду
        ├── stores/         ← кошик, авторизація, повідомлення
        ├── components/     ← шапка, футер, картка товару…

```

## API (для довідки)

| Метод | Адреса | Опис |
|---|---|---|
| GET | `/api/categories` | дерево категорій |
| GET | `/api/brands` | виробники |
| GET | `/api/products?search=&category=&brand=&crop=&minPrice=&maxPrice=&inStock=1&sort=&page=` | каталог |
| GET | `/api/products/filters?category=` | дані для фільтрів |
| GET | `/api/products/:slug` | картка товару + схожі товари |
| POST | `/api/orders` | оформлення замовлення (ціни рахуються на сервері) |
| POST | `/api/requests` | заявка (консультація / протруювання / дзвінок) |
| POST | `/api/auth/login` | вхід адміністратора |
| * | `/api/admin/...` | товари, категорії, виробники, замовлення, заявки (потрібен токен) |
